## 18+ 与免责

本测试仅面向 18 岁以上成年人。

本测试为面向成年人的娱乐向自我观察，非正式性心理测量或临床评估，不能替代专业心理咨询、性健康咨询或医疗建议。题目用隐喻和日常情景描述亲近时的节奏与表达习惯，不涉及具体行为指导，也不对任何人的偏好做道德评判。「麋鹿」只是一种趣味画像，结果会受当下心情与理解方式影响；图一乐、拿去分享都可以，别把它当成性取向鉴定、人格判决或关系诊断书。

偏好没有高低对错，只要建立在自愿、尊重和清晰界限上。若题目让你不适，随时可以离开。若亲密关系中出现强迫、伤害或不被尊重，请寻求可信赖的人或正规支持，而不是用一份娱乐测试替你做决定。

## 文件

- `index.html` — 单文件 H5（内联 CSS / JS），GitHub Pages 从仓库根目录提供
- `.nojekyll` — 让 Pages 按静态文件发布，不走 Jekyll
- `CODES.md` — 验证码格式与规则（无可卖码）
- `tools/mint.sh` — 只打印 vault 造码用法，不生成、不写入真码

## 本地预览

```bash
python3 -m http.server 8080
```

浏览器打开 http://127.0.0.1:8080/ 。未确认满 18 岁时，点「开始测试」或「已有码，直接进入」只会先出现年龄确认，题目和验证码框都不会出现。确认年龄后才会要求验证码。未解锁时题目不会进入作答屏。「查看上次结果」只在本机有过结果时出现在封面上，且只读本地缓存。

## 码规则（不要把可卖码写进仓库）

- 前缀 `EL`，后接 4 位，字符表不含 I / L / O / 0 / 1
- Vault quiz key：`elk`（发码池 `pools/elk.txt`，由 vault 维护，不在本仓库）
- 造码只在 companion vault 上做，见 `tools/mint.sh` 与 `CODES.md`
- 本仓库不存放可卖验证码、ADMIN、PAT 或任何密钥
